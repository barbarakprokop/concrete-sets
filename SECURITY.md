# Public technical companion security note

This is not the original mobile app repository. It contains only standalone examples and synthetic data. There are no native project files, Apple certificates, provisioning profiles, private identifiers, audio assets, account information or environment keys.

Do not paste full Xcode project settings, export credentials or private deployment configuration into this repository. Public sample logic is not a secure workout tracking or health monitoring system. The watch state example does not contact a real device.

Report suspected disclosure privately through [the portfolio](https://barbarakprokop.com/productdesign/).
